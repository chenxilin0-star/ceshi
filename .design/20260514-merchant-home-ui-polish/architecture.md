# 商户中心首页 UI 优化设计

## 目标
- 优化 `miniprogram/pages/merchant-home/index` 商户中心首页视觉质感。
- 保持现有功能与路由完全不变：商品管理、扫码核销、核销记录、抽奖配置入口仍调用原事件。

## 设计方案
- 顶部升级为经营驾驶舱 Hero：渐变背景、商户身份标签、运营状态提示。
- 中间加入概览卡片：表现“4 个管理模块 / 即时核销 / 活动配置”等静态视觉信息，不依赖新增数据。
- 操作入口改为更有层级的卡片网格：图标光圈、标题、说明、进入箭头。
- 增加操作提示区：突出商户日常管理路径。

## 约束
- 不改 JS 业务逻辑。
- 不改云函数、数据库、API。
- 保留所有 `bindtap` 事件名称。
- 不引入新依赖，不新增运行时数据字段。
