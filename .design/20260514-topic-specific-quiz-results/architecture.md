# 首页测试同题材结果重复修复设计

## 用户反馈
首页截图中的测试包括：
- 精神内耗指数测试
- 情绪管理风格测试
- 社交恐惧程度测试
- 压力指数测试

这些测试目前容易使用同一套 `state/recharge` 分数结果，导致不同题目结果标题和解读高度重复。另有：
- 恋爱脑测试
- MBTI 恋爱人格测试

两者都被归入 `love`，目前动态拼接结果相似，缺少主题差异。

## 根因
1. 服务端 `submitTest/resultLogic.js` 的 domain 粒度过粗：`状态/摆烂/回血/电量` 都进入同一套 state 分数池。
2. 前端 `testResultPresenter.js` 结果页同样只按 `recharge/love/social` 大类兜底，缺少题目级 subtype。
3. 线上运营测试不一定在本地 `seedTests`，所以必须按标题/分类关键词做更细的主题兜底，而不能依赖固定 5 个 seed。

## 修复方案
### 服务端
新增 topic subtype 识别：
- `mentalDrain`：精神内耗指数测试
- `emotionManage`：情绪管理风格测试
- `socialAnxiety`：社交恐惧程度测试
- `stress`：压力指数测试
- `loveBrain`：恋爱脑测试
- `mbtiLove`：MBTI 恋爱人格测试

每个 subtype 使用独立结果池：
- 精神内耗：内耗过载型 / 反复拉扯型 / 自我校准型 / 松弛稳定型
- 情绪管理：情绪风暴型 / 忍住不说型 / 稳定调节型 / 情绪导航员
- 社交恐惧：社交省电型 / 熟人舒适型 / 选择性社交型 / 社交自来熟
- 压力指数：压力爆表型 / 高压绷紧型 / 可控压力型 / 轻压前行型
- 恋爱脑：上头雷达型 / 反复脑补型 / 清醒心动型 / 边界稳定型
- MBTI 恋爱：慢热守护者 / 稳定陪伴者 / 直球行动者 / 浪漫探索者

### 前端
结果页 presenter 同步这些 subtype，保证历史结果/旧云函数结果也不会继续展示同一套文案。

## 非目标
- 不修改答题流程。
- 不修改页面跳转/积分/抽奖功能。
- 不新增依赖。
- 不改数据库结构。
