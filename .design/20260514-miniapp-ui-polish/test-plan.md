# Test Plan

## 静态验证
1. 运行项目现有 `npm run validate`（若存在）。
2. 校验所有 `.json` 文件可解析。
3. 校验所有已注册页面的 `.wxml/.wxss/.js/.json` 文件存在。
4. 搜索确认关键事件绑定仍存在：积分上传、重新选择、确认提交、商品兑换、分享按钮。

## 手工预览建议
- 微信开发者工具打开：
  - 首页
  - 积分页
  - 分销页
  - 我的
  - 测试详情/结果
  - 商品/优惠券/商家相关页面
- 检查按钮是否被微信默认 `button:not([size="mini"])` 宽度影响。
- 检查小屏下列表记录是否换行、溢出。

## 通过标准
- 功能文件无业务逻辑变更。
- 校验脚本通过。
- `git diff` 仅体现 UI/设计文档相关改动。
