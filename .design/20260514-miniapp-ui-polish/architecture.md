# 趣测星球小程序 UI 美工优化设计

## 目标
- 拉取用户最新代码后，仅做前端视觉美化，不改变业务功能、云函数、数据结构与页面跳转逻辑。
- 重点优化 `miniprogram/pages/points/index` 与 `miniprogram/pages/referral/index`（分销）。
- 对所有已注册页面进行统一视觉体系梳理：背景、卡片、按钮、列表、空状态、表单与商家后台页面保持一致的 Dreamy Candy 风格。

## 范围
- 可改：`.wxml` 的纯展示结构/装饰节点、`.wxss` 视觉样式、全局 `app.wxss` 的通用样式增强、页面 `.json` 标题（如必要）。
- 不改：`.js` 业务逻辑、云函数、数据库 seed、事件绑定名、`wx:for`/`wx:if` 条件、表单字段名、跳转函数名。

## 视觉方向
- 主题：梦幻糖果 / 校园娱乐 / 年轻化。
- 色彩：沿用全局 `#FF7EB3`、`#B388FF`、`#82B1FF`、`#FFB74D`，避免引入冲突主色。
- 布局：顶部 Hero + 浮层卡片 + 柔和阴影 + 清晰行动按钮。
- 细节：使用 badge、渐变光斑、分区标题、圆角列表卡片、精致空状态提升完成度。

## 页面策略
1. 积分页：强化积分资产感、上传凭证流程感、OCR 结果卡片与历史记录层次。
2. 分销页：强化推广收益仪表盘、规则说明、分享 CTA 与收益记录可读性。
3. 首页、测试详情、结果、商品/优惠券、我的、商家页面：统一卡片质感、标题层级、按钮与列表间距。

## 风险控制
- 保留所有 `bindtap`、`open-type`、`data-*`、`wx:key`、模板变量。
- 不引入需要运行时计算的新数据字段。
- 不添加前端发放积分、分享解锁等功能逻辑。
