# 测试计划

## 静态验证
1. `node --check` 校验所有 JS 文件语法。
2. JSON parse 校验所有 JSON 文件。
3. 校验 `app.json` 页面文件完整。
4. 校验前端云函数调用均有对应 `cloudfunctions/<name>` 目录。

## 首页逻辑验证
1. `getTests` 成功返回列表：
   - 首页显示 Hero、6 类频道、每日任务、推荐测试。
   - Hero 主按钮能进入 featuredTest。
   - 推荐测试卡片能进入详情。
2. `getTests` 返回空：
   - 首页仍显示 Hero、6 类频道、每日任务。
   - 推荐测试区域显示空状态。
   - Hero 主按钮提示“今日内容准备中”。
3. `getTests` 失败：
   - 页面不崩溃，loading 结束。
   - 首页静态内容可见。
4. 分类点击：
   - 有匹配测试时进入该测试。
   - 无匹配测试时提示“内容上新中”。
5. 登录行为：
   - 首页浏览不强制登录。
   - 进入测试沿用 `requireLogin`。

## UI 验证
1. iPhone 窄屏：卡片不溢出，2 列频道间距正常。
2. 长标题：推荐测试标题/描述有截断，不撑破卡片。
3. 空数据：页面不显得空白。
4. 触摸反馈：主卡片、频道卡片、测试卡片有 active 状态。
5. 合规文案：页面可见“校园娱乐参考”定位，不出现诊断/预测/恋爱诱导。

## 回归验证
1. 积分兑换入口仍可跳转商品列表。
2. 测试详情页仍按 `testId` 加载。
3. 分享标题不再使用“测性格”单一文案，改为校园娱乐定位。
4. 无新增外部 API、无新增敏感信息。
