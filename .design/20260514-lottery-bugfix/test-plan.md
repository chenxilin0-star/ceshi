# 测试计划

## 自动化
- `node tests/lottery-logic.test.js`
  - 默认每日仅 1 次免费机会。
  - 分享前不能使用 share 抽奖。
  - 分享后增加 1 次 share 抽奖。
  - 分享机会每日最多 2 次。
  - share 抽奖会消耗已获得分享机会。
  - 奖品 order 可以映射到正确转盘扇区。

## 静态校验
- `node --check` 校验所有变更 JS 文件。
- JSON 文件可解析。
- `git diff --check` 无格式问题。

## 手工验收
1. 新用户/当天未抽奖进入抽奖页，应显示 1 次机会。
2. 抽完 1 次后，无分享机会时应显示 0 次。
3. 点击分享后返回，应增加 1 次分享机会。
4. 每天分享最多增加 2 次。
5. 指针落在哪个扇区，弹窗奖品名称应与该扇区一致。
