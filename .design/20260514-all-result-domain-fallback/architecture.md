# 全测试结果域修复设计

## 问题
前一轮只把「校园人设」「干饭奶茶」两个域的泛化结果兜底成具体结果。其余测试如果云数据库仍返回「结果已生成 / 已完成 / 你的校园搭子属性已生成 / 你的今日校园状态已生成」等生成态标题，结果页仍会表现为老样子。

## 根因
- `submitTest/resultLogic.js` 的 domain fallback 只覆盖 persona、food、consume。
- `miniprogram/utils/testResultPresenter.js` 的历史结果兜底只覆盖 persona、food、consume。
- 朋友搭子是 dimension 模式，但没有 social 维度兜底映射。
- 今日校园状态 / 摆烂回血是 score 模式，但没有 daily/recharge 分数区间兜底映射。

## 设计
### 服务端 submitTest
新增覆盖所有首页测试域的兜底：
- 校园人设：维度/分数 -> 班级角色。
- 干饭奶茶：维度/分数 -> 饮食人格。
- 朋友搭子：维度 -> 朋友角色。
- 今日校园状态：分数区间 -> 今日状态。
- 摆烂回血：分数区间 -> 电量状态。
- 消费风格：保留已有分数区间兜底。

### 前端历史结果 presenter
同样覆盖所有测试域，保证历史记录、旧数据库记录、未重新 seed 的数据也不会继续显示生成态标题。

## 非目标
- 不改页面交互流程。
- 不改答题流程。
- 不改云函数 API 入参/出参结构。
- 不引入依赖。
